WEBSITE PROFILE - HUONG DAN
1. Giải nén file ZIP.
2. Mở index.html bằng trình duyệt để xem.
3. Sửa tên, mô tả, link mạng xã hội trong index.html.
4. Thêm ảnh đại diện tên avatar.jpg vào cùng thư mục.
5. Thay nội dung Donate / QR bằng thông tin của bạn.
6. Có thể upload thư mục lên GitHub Pages, Netlify hoặc Vercel để chạy online.

Đây là giao diện lấy cảm hứng từ phong cách website profile; không sao chép nguyên văn nội dung/nhận diện của website tham khảo.
